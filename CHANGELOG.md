# Changelog

## 1.1.0

- Added an optional Windows launcher and loopback-only CDP injection host.
- Added Endfield contour rendering, industrial control feedback, `ENDFIELD` watermark, startup loader, task status plates, and Shadow DOM settings.
- Added strict turn-event adapters for renderer messages, custom notifications, and WebSocket frames; paused contour rendering on scroll, hidden pages, and reduced motion.
- Made the Windows interactive enhancement layer the sole published mode and renamed user-facing client copy to ChatGPT.
- Added configuration, event-edge, storage, CDP, and isolated Chromium fixture tests.
